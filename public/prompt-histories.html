Property ROI

~14 hours across 12+ sessions

A real estate investment analysis dashboard — charts, CAGR/IRR/Cash-on-Cash metrics, a portfolio scraper, and a growing set of pages (Scout, Comparison, Deal Analyzer, Property Detail, Admin) built out one at a time. Two threads run through these: getting a new page/view actually built and wired up, and — since a chart can render a confident-looking number that's just wrong — catching when a result doesn't match intuition and figuring out what would actually prove it right. Total dev time is this project's own tracked figure, from its project summary file.
